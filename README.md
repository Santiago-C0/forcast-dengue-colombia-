# forcast-dengue-colombia-
Pronóstico de casos semanales de dengue en Colombia con modelos ARIMA, SARIMA y SARIMAX (términos de Fourier), comparados con el canal endémico del INS (método de Bortman). Datos Sivigila 2019–2025, réplica del canal con diferencia menor al 1 % y evaluación por RMSE, MAE, MAPE y MASE a 1 semana, 4 semanas y año completo.
